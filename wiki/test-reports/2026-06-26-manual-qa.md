## 5. Findings (Severity)

### F-1 — Default `evidence_files.kind` policy tidak include `link` polos (LOW)
**Konteks:** RPC `submit_action_plan` melempar payload `kind` apa adanya. CHECK constraint membatasi ke `file|photo|screenshot|pdf|link_gdrive|link_doc|text_note|report`. Submission dengan `kind="link"` polos → 23514.
**Dampak:** UI mobile harus tahu mapping; bila future-link sources (Notion, Figma, dll) ditambah, perlu DDL.
**Saran:** Tambah `link_generic` ke whitelist atau dokumentasikan jelas di `wiki/concepts/evidence-kinds.md`.

### F-2 — Auth: leaked password protection nonaktif (MEDIUM)
Aktifkan via dashboard Supabase → Auth → Security.

### F-3 — `public.settings` duplicate unique index (MEDIUM)
DROP salah satu dari `settings_org_key_uniq` / `settings_organization_id_key_key`.

### F-4 — `auth_rls_initplan` 42 policies (MEDIUM)
Refactor policy: `(select auth.uid())` ganti `auth.uid()`. Auto-fixable.

### F-5 — Profile trigger paksa role=staff saat INSERT direct (LOW/INFO)
Saat suntik profile via INSERT (bukan via RPC), `role_template_id` di-override ke staff terlepas dari yang dikirim. Bukan path user-facing (signup biasa via auth → trigger handle), tapi merepotkan saat seeding QA / migrasi staff↔management bulk. Saran: bila `service_role`, hormati nilai input.

### F-6 — Belum ada index `(entity_type, entity_id)` di hot table observability (MEDIUM)
`notifications`, `activity_logs`, `governance_violations` sering di-query lewat 2 kolom ini. Lihat advisor `unindexed_foreign_keys`. Saran: composite index sebelum scale.

### F-7 — Tidak ada keterangan `body` panjang di notifikasi (LOW)
Semua notif body cuma nama AP. Pertimbangkan tambahkan ringkasan keputusan ("Disetujui oleh CEO Nyantuy Group") agar lebih kontekstual saat dibuka 1 hari kemudian.

### F-8 — Belum ada `auth-leaked-password` config + smoke-test login otomatis (LOW)
Smoke login `aksalalsal23@gmail.com` via mobile app tidak bisa dieksekusi dari CLI (butuh device Expo). Saya validasi sesi via JWT impersonation di DB sebagai pengganti. **Rekomendasi:** EAS preview build untuk QA berikutnya, atau Detox/Playwright Android.
